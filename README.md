# Signal to Agents

Blog personal sobre agentes de IA, LLMs locales e ingeniería de telecomunicaciones. Hecho con [Astro](https://astro.build) y publicado en Cloudflare Pages.

- Posts: `src/content/blog/`
- Configuración del sitio: `src/consts.ts`, `astro.config.mjs`
- Publicar: `bash scripts/publish.sh` (GitHub + Cloudflare Pages)
- Cómo publicar: [DEPLOY.md](DEPLOY.md)
- Borrador para LinkedIn: [LINKEDIN.md](LINKEDIN.md)

```bash
npm install && npm run dev
```
